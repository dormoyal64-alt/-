# ניהול עבודות וקבלנים

מערכת ניהול עבודות לעסק שמפרסם ומתאם עבודות בכמה תחומים (אינסטלציה, ניקוי
מזגנים, תיקון מזגנים, ועוד תחומים שתוסיפו בעצמכם). המערכת פועלת גם כאתר וגם
כ־**אפליקציה (PWA)** — ניתן "להתקין" אותה למסך הבית בפלאפון או למחשב, והיא
עובדת מכל מכשיר עם אותם נתונים בדיוק (הנתונים מסונכרנים בענן דרך Firebase).

## מה יש במערכת

- **ניהול תחומי עבודה** — רשימה פתוחה שאפשר להוסיף אליה תחומים בעתיד.
- **קבלני ביצוע** לכל תחום, עם טלפון ואחוז עמלה לברירת מחדל.
- **ערים** — רשימת ערים מוכנה מראש בישראל, עם אפשרות להוסיף עוד.
- **עבודות** — לכל עבודה: לקוח (שם/טלפון/כתובת), תאריך, סכום, אופן תשלום,
  מי גבה את התשלום בפועל (הקבלן או אתם), ואחוז עמלה. המערכת מחשבת אוטומטית
  כמה מגיע לכם מהעבודה, ובהתאם למי גבה את הכסף — האם **הקבלן חייב להעביר
  לכם**, או **אתם חייבים להעביר לקבלן**.
- **דוחות שבועיים** לכל קבלן (או לכולם יחד) — כמה עבודות בוצעו, מחזור, עמלה
  ויתרת חוב לכל שבוע (ראשון–שבת).
- **דשבורד עם גרפים** — עבודות לפי עיר, עבודות לפי תחום, וכמה עבודות כל קבלן
  קיבל מול כמה נסגרו.
- ממשק בעברית, מותאם RTL, ועובד טוב גם בפלאפון וגם במחשב.

## איך זה עובד מאחורי הקלעים

זהו אתר סטטי (React) שמתחבר ל־**Firebase** (שירות חינמי של גוגל) לצורך
התחברות למערכת ואחסון הנתונים. כך אותו מידע מופיע בדיוק אותו הדבר גם
מהמחשב וגם מהפלאפון, בזמן אמת.

## הקמת Firebase (חד־פעמי, כ־10 דקות)

1. **יצירת פרויקט**: כנסו ל-<https://console.firebase.google.com>, לחצו
   "Add project" וצרו פרויקט חדש (אפשר לבטל את Google Analytics, לא נדרש).
2. **הפעלת התחברות**: בתפריט הצד → Build → **Authentication** → לשונית
   Sign-in method → הפעילו את הספק **Email/Password**.
3. **יצירת המשתמש שלכם**: באותו מסך Authentication → לשונית Users → **Add
   user** → הזינו את האימייל והסיסמה שאיתם תתחברו למערכת (זה חשבון
   הבעלים, לא צריך הרשמה עצמית מהאתר).
4. **הפעלת מסד נתונים**: בתפריט הצד → Build → **Firestore Database** →
   Create database → מומלץ להתחיל ב-**Production mode** ולבחור מיקום קרוב
   (למשל `eur3` / `europe-west`).
5. **פרסום כללי האבטחה**: בלשונית Rules של Firestore, הדביקו את התוכן של
   הקובץ [`firestore.rules`](./firestore.rules) מהתיקייה הזו ולחצו Publish.
   הכללים דואגים שרק אתם (המשתמש המחובר) יכולים לראות ולערוך את הנתונים שלכם.
6. **קבלת פרטי החיבור**: בתפריט הצד → **Project settings** (גלגל השיניים) →
   גללו למטה ל-"Your apps" → לחצו על סמל ה-Web `</>` → תנו שם לאפליקציה
   ולחצו Register. יופיעו לכם 6 שדות (`apiKey`, `authDomain` וכו').
7. **מילוי הפרטים בקוד**: פתחו את הקובץ [`src/firebaseConfig.ts`](./src/firebaseConfig.ts)
   והחליפו כל ערך שמתחיל ב-`REPLACE_` בערך המתאים מהשלב הקודם.

זהו — לאחר מילוי הקובץ ופרסום, האתר יתחבר אוטומטית ל-Firebase שלכם.

## הרצה מקומית (לבדיקה על המחשב שלכם)

```bash
npm install
npm run dev
```

יפתח שרת פיתוח בכתובת שתוצג בטרמינל.

## בנייה ופרסום לאינטרנט

```bash
npm run build
```

הפקודה יוצרת תיקיית `dist/` — תוכן סטטי בלבד שאפשר להעלות לכל שירות
אחסון סטטי (GitHub Pages, Netlify, Vercel, Firebase Hosting וכו'). אחרי
העלאה, פתחו את הכתובת בדפדפן הפלאפון ובחרו "הוספה למסך הבית" /
"Install app" כדי שהיא תתנהג כאפליקציה לכל דבר.

## מבנה תיקיות עיקרי

```
src/
  firebaseConfig.ts   פרטי החיבור ל-Firebase — נקודת העריכה היחידה
  types.ts            מבנה הנתונים וחישוב היתרות
  pages/               ראשי, עבודות, דוחות שבועיים, ניהול
  components/          רכיבי ממשק משותפים
firestore.rules        כללי אבטחה להדבקה בקונסולת Firebase
```
