# ביובית בדרום — דף נחיתה

דף נחיתה סטטי (HTML/CSS/JS ללא תלויות חיצוניות) שמטרתו להמיר מבקרים לשיחות טלפון ופניות WhatsApp.

## מבנה הקבצים

```
index.html              דף הנחיתה
assets/css/style.css    כל העיצוב
assets/js/config.js     כל פרטי העסק ומזהי המעקב — נקודת העריכה היחידה
assets/js/main.js       לוגיקה: הזרקת הפרטים מה-config, מעקב אירועים, אנימציות, טופס
```

## מה חייבים להשלים לפני פרסום (`assets/js/config.js`)

כל שדה שמתחיל ב-`REPLACE_` הוא Placeholder ולא מידע אמיתי — עד שהוא לא יוחלף, הכפתורים הרלוונטיים (טלפון/וואטסאפ) ינווטו לטופס יצירת הקשר בתחתית הדף במקום להתחבר ישירות.

| שדה | מה להזין |
|---|---|
| `ownerName` | שם בעל העסק |
| `phoneDisplay` / `phoneE164` | מספר טלפון להצגה ולקישור חיוג (פורמט בינלאומי, לדוגמה `+972501234567`) |
| `whatsappNumber` | מספר וואטסאפ בפורמט בינלאומי ללא `+` |
| `serviceAreas` | רשימת יישובים בפועל. אם ריקה — יוצג טקסט כללי על אזור הדרום |
| `hours` | שעות פעילות (יוצג רק אם מולא) |
| `googleReviewsUrl` | קישור לביקורות גוגל |
| `images` / `logoUrl` | נתיבים לתמונות אמיתיות (בעל מקצוע, רכב, לפני/אחרי, עבודות) |
| `tracking.*` | מזהי GA4 / Google Ads / Meta Pixel — למלא רק מזהים אמיתיים |
| `formEndpoint` | אופציונלי: Webhook לשליחת הטופס ל-CRM/Sheets. אם ריק, הטופס מפנה להודעת WhatsApp מוכנה מראש |

## מה עוד דורש השלמה ידנית בקוד

- **`index.html` — `<head>`**: `REPLACE_WITH_PAGE_URL`, `REPLACE_WITH_OG_IMAGE_URL`, `REPLACE_PHONE_E164`, `REPLACE_WITH_LOGO_OR_PHOTO_URL` ב-JSON-LD.
- **Schema.org**: הוגדרו רק שדות שסופקו בפועל (שם, טלפון, אזור שירות, תמונה). לא נוספו דירוג, מספר ביקורות, כתובת מדויקת, שעות פעילות או טווח מחירים — הוסיפו אותם ל-JSON-LD רק אם יש נתונים אמיתיים.
- **ביקורות** (`#reviews`): שלושה כרטיסי Placeholder מסומנים בבירור — יש להחליף בביקורות Google אמיתיות (כוכבים בפועל, שם לקוח, עיר וטקסט).
- **תמונות**: מקום ה-Hero מציג Placeholder מעוצב במקום תמונת סטוק. יש להחליף בתמונות אמיתיות של בעל המקצוע / הרכב / עבודות.
- **מעקב (Analytics/Ads/Pixel)**: הסניפטים מוכנים כהערה ב-`<head>` של `index.html`. הסירו את ההערה ומלאו מזהים אמיתיים בלבד.

## אירועי מעקב מוכנים

`phone_click`, `whatsapp_click`, `form_submit`, `hero_cta_click` — נשלחים אוטומטית ל-`gtag`/`fbq` אם הם נטענים בעמוד (ראו `main.js`).

## הרצה מקומית

קובץ סטטי בלבד — פותחים את `index.html` בדפדפן, או מגישים את התיקייה בכל שרת סטטי (Netlify, GitHub Pages, Vercel וכו').
