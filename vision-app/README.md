# SeeTuned · סיטיונד

**המסך שלך, מכוון לעיניים שלך.** — *Your screen, tuned to your eyes.*

אפליקציית PWA לטלפונים ולטאבלטים (אנדרואיד ו-iPhone/iPad, מותקנת ממסך הבית). היא בודקת כל עין בנפרד בבדיקות קצרות על המסך, בונה פרופיל ראייה אישי ומתאימה את התצוגה:

- **האפליקציה עצמה:** גודל טקסט, עובי, ריווח, ניגודיות וסינון צבע.
- **תמונות, סרטונים, זכוכית מגדלת חיה (מצלמה) וקורא טקסט:** מעובדים בזמן אמת לפי הפרופיל.
- **כל הטלפון:** מדריך צעד-אחר-צעד עם הערכים המדויקים להגדרות הנגישות של המכשיר (iOS, iPadOS, אנדרואיד, סמסונג).
- **אנדרואיד ו-Galaxy:** אפליקציית SeeTuned לאנדרואיד מחילה את ההגדרות בעצמה, אחרי שהמשתמש מאשר לה גישה:
  - גודל הטקסט משתנה בכל הטלפון.
  - לשאר ההגדרות היא פותחת את המסך הנכון.
  - ״עדשה״ מגדילה ומחדדת כל מסך, בכל אפליקציה.
  - פרטים: `docs/android/ANDROID-APP.md`.

המודל העסקי הוא חודש ניסיון חינם בלי כרטיס אשראי, ואחריו מנוי חודשי, ל-3 חודשים או לשנה, בתשלום מאובטח בעמוד המאובטח של ספק התשלומים.

## מה המוצר לא עושה (חשוב לשיווק)

- זה כלי להתאמת תצוגה ולנוחות צפייה, **לא מכשיר רפואי, לא אבחנה ולא מרשם**.
- מסך רגיל לא יכול לתקן אופטית טשטוש שנובע מהעין. אנחנו מתאימים גודל, ניגודיות, צבע וחדות.
- האפליקציה לא מציגה סימון קליני (כמו 6/12 או דיופטרים). כשהתוצאות מצדיקות זאת היא ממליצה לפנות לאופטומטריסט או לרופא עיניים.
- תוצאות בדיקות העיניים נשמרות **רק במכשיר של המשתמש** ולא נשלחות לשרת.

ניסוחים מותרים ואסורים: `docs/research/business-legal-payments.md` (סעיף 5) ו-`docs/brand/BRAND.md`.

## הרצה מקומית

דרישות: Node.js 22.13 ומעלה.

```bash
cd vision-app
npm install                 # מתקין תלויות ומוריד את מודל המצלמה של MediaPipe לתיקיית vendor
SESSION_SECRET=dev-secret-at-least-32-characters-long npm run dev
```

פתחו http://127.0.0.1:3000/ (אתר השיווק) או http://127.0.0.1:3000/app/ (האפליקציה).

בפיתוח ספק התשלומים הוא `mock`: עמוד תשלום לבדיקה, בלי כסף אמיתי.

## שימוש בלי משקפיים: מה נבדק

ברירת המחדל באפליקציה היא שימוש בלי משקפיים: הבדיקות נעשות בלי משקפיים, ובסופן מתקבלת המלצה על מרחק ועל גודל טקסט.

הבדיקה נעשתה עם 61 משתמשים מדומים, כל אחד 20 פעמים, על בסיס מודל אופטי של העין עם מקורות. התוצאות:

| קבוצה | התוצאה |
|---|---|
| קוצר ראייה עד -3, רוחק ראייה עד גיל 45, צילינדר עד 0.75 | נוח בלי משקפיים |
| קוצר ראייה -4, צילינדר 1.5 עד 2.5, גיל 45 עד 55 | חלקי: טקסט גדול או מרחק קרוב |
| קוצר ראייה -5 ומעלה, פרסביופיה מגיל 55 ומעלה | לא מעשי: האפליקציה ממליצה להמשיך עם משקפיים |
| מתחת לגיל 18 | אף פעם לא מומלץ בלי משקפיים |

קריאה נוחה בלי משקפיים עלתה מ-41% בהגדרות הרגילות של הטלפון ל-80% עם הפרופיל של SeeTuned. הדוח המלא: `docs/validation/SIMULATION-REPORT.md`.

זו סימולציה, לא הוכחה. לפני כל טענה שיווקית צריך פיילוט עם אנשים אמיתיים.

## פיילוט עם משתמשים אמיתיים

- **מפגש בודק:** בעמוד `/pilot/session.html`. הבודק קורא קטע קצר בשלושה מצבים: עם משקפיים, בלי משקפיים בהגדרות רגילות, ובלי משקפיים עם SeeTuned. ביניהם הוא עובר את בדיקת האפליקציה.
- **טבלת התוצאות:** בעמוד `/pilot/hub.html`, ובגרסת ההדגמה בעמוד הפתיחה. יש בה אחוז הצלחה, ייבוא קוד תוצאות מבודק מרוחק, וייצוא CSV.
- **הנחיות להפעלה:** `docs/pilot/PILOT-PROTOCOL.md`, כולל קריטריוני ההצלחה וגודל המדגם המומלץ.

## אפליקציית אנדרואיד

הקוד ב-`android/`. הבנייה צריכה את ה-Android SDK ואת המאגר של Google:

```bash
cd android
./gradlew assembleDebug                         # APK לבדיקה
./gradlew -PcoreOnly :core:test :compilecheck:compileKotlin   # בלי Android SDK: בדיקות הליבה ובדיקת קומפילציה
```

ב-GitHub Actions (`.github/workflows/android.yml`) כל דחיפה:

- בונה את ה-APK ומריצה Lint.
- מריצה בדיקות על אמולטורים של אנדרואיד 11 ו-15.
- מצרפת את `app-debug.apk` לריצה, להתקנה בפיילוט.

## גרסת הדגמה (בלי שרת)

```bash
npm run demo    # בונה את dist-demo/: האפליקציה, אתר השיווק ועמודי המשפט, עם קישורים יחסיים
```

גרסת ההדגמה עובדת בכל אחסון של קבצים סטטיים. במקום השרת יש תחליף שרץ בדפדפן, והמידע נשמר רק בדפדפן של המשתמש.

- ההרשמה, המנוי והתשלום מדומים. אין תשלום אמיתי ואין מיילים.
- המצלמה והעבודה בלי אינטרנט לא כלולות בהדגמה.

## איך קובעים מחירים (כשתחליטו)

המחירים הם משתני סביבה, ביחידות אגורות וכוללים מע״מ. מה שמוגדר עכשיו הם מחירים זמניים:

```bash
PRICE_MONTHLY=2490     # ₪24.90 לחודש
PRICE_QUARTERLY=5990   # ₪59.90 ל-3 חודשים
PRICE_YEARLY=17990     # ₪179.90 לשנה
TRIAL_DAYS=30          # אורך תקופת הניסיון
```

למחירים בחו״ל (דולר, דרך Paddle) יש משתנים נפרדים: `PRICE_INTL_*`. הם חייבים להתאים למחירים שמוגדרים בחשבון Paddle.

אחוזי החיסכון מחושבים אוטומטית, ואתר השיווק מושך את המחירים מהשרת.

## תשלומים

- **ישראל:** PayPlus. עמוד תשלום מאובטח, ביט, Apple Pay ו-Google Pay, וחשבונית מס/קבלה אוטומטית.
- **חו״ל:** Paddle, שפועל כ״מוכר רשום״ וגובה את המסים בעצמו.
- מספרי כרטיסים אף פעם לא עוברים בשרת שלנו.
- כל משתני הסביבה מתועדים ב-`server/.env.example`.
- לפני עלייה לאוויר צריך לאמת בסביבת הבדיקות (sandbox) של כל ספק את השדות שמסומנים [CHECK] ב-`server/billing/providers/README.md`.

כללי המנויים, לפי חוק הגנת הצרכן:

- **חודשי:** מתחדש אוטומטית, עם תזכורת לפני כל חיוב.
- **3 חודשים ושנה בישראל:** תשלום אחד מראש, בלי חידוש אוטומטי. יש תזכורות לפני הסיום, וחידוש רק בהסכמה מפורשת.
- **ביטול:** בלחיצה אחת, בלי דמי ביטול.
- **החזר מלא:** בביטול בתוך 14 יום מהתשלום.

## עלייה לאוויר (Deployment)

1. שרת Node.js 22 עם HTTPS, ותיקיית נתונים קבועה (`DATA_DIR`, מסד SQLite) עם גיבוי יומי.
2. משתני חובה בייצור:
   - `NODE_ENV=production`
   - `PUBLIC_BASE_URL=https://your-domain`
   - `SESSION_SECRET` באורך 32 תווים לפחות
   - `PAYMENT_PROVIDER`, ומפתחות הספק.
3. מאחורי reverse proxy או load balancer: להגדיר `TRUST_PROXY=1`. אחרת הגבלת הקצב תחסום את כולם יחד.
4. שליחת מיילים (איפוס סיסמה, תזכורות, אישורי ביטול): להגדיר את `MAIL_PROVIDER=http` ואת `MAIL_HTTP_URL`, `MAIL_HTTP_TOKEN` ו-`MAIL_FROM`.
5. `npm start`. השרת מסרב לעלות אם ההגדרות לא בטוחות.
6. בכל עדכון לקבצי האפליקציה: להעלות את `VERSION` ב-`public/app/sw.js`, כדי שמכשירים יקבלו את הגרסה החדשה.
