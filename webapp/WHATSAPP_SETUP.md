# חיבור שליחה אוטומטית ב-WhatsApp

בלי החיבור הזה המערכת עובדת: הכפתור בעבודה פותח וואטסאפ עם ההודעה מוכנה, ואתם
לוחצים שלח. עם החיבור, פרטי ההזמנה נשלחים ללקוח לבד ברגע שהעבודה נשמרת.

## לפני שמתחילים — החלטה אחת חשובה

מספר טלפון שנרשם ל-WhatsApp Business API **מתנתק מאפליקציית וואטסאפ הרגילה**.
לא תוכלו יותר לפתוח את השיחות שלכם באותו מספר מהטלפון.

לכן: **כדאי לייעד מספר נפרד** לשליחה האוטומטית (כרטיס SIM נוסף, או מספר וירטואלי),
ולהשאיר את המספר שאתם מדברים בו עם לקוחות וקבלנים כפי שהוא.

בהגדרות המערכת אפשר להגדיר מספר אחר ל״יצירת קשר, שינוי וביטול״ — כך ההודעה
נשלחת מהמספר הייעודי, אבל הלקוח מתבקש להתקשר למספר הרגיל שלכם.

## מה צריך להביא מ-Meta

1. **Meta Business Manager** → business.facebook.com, עם העסק המאומת שלכם.
2. **WhatsApp Business Account (WABA)** → מוסיפים את המוצר WhatsApp.
3. **מספר טלפון** → Phone Numbers → Add phone number → אימות ב-SMS.
   בסיום מעתיקים את ה-**Phone number ID** (מספר ארוך, לא הטלפון עצמו).
4. **טוקן קבוע** → Business Settings → System Users → יוצרים System User עם
   הרשאת `whatsapp_business_messaging`, מפיקים טוקן ובוחרים **Never expires**.
   טוקן שמופק במסך הבדיקה תקף 24 שעות בלבד — הוא לא מתאים.
5. **תבנית הודעה מאושרת** → ראו למטה.

## התבנית

WhatsApp מרשה לעסק לפתוח שיחה רק בנוסח שאושר מראש. ב-Message Templates יוצרים
תבנית חדשה:

- **Name:** `order_confirmation`
- **Category:** Utility
- **Language:** Hebrew

**Body** — המשתנים `{{1}}`–`{{5}}` מתמלאים על ידי המערכת לפי הסדר:
שם הלקוח, כתובת, סוג התקלה, מועד הגעה, סכום דמי הביקור.

```
שלום {{1}},

להלן פרטי הזמנת השירות:

• כתובת השירות: {{2}}
• סוג התקלה: {{3}}
• מועד הגעה משוער: {{4}}

דמי הביקור והאבחון הם {{5}}, כולל כל מס החל, והם משולמים עבור הגעת בעל המקצוע ובדיקת התקלה — גם אם לאחר הבדיקה תבחר/י שלא להזמין עבודה נוספת.

אם יהיה צורך בעבודה, חלקים או ציוד נוסף, המחיר יימסר לך בנפרד ויבוצע רק לאחר קבלת אישורך.

ניתן לבטל את ההזמנה ללא חיוב כל עוד הטכנאי טרם יצא לדרך. לאחר שהטכנאי יצא לדרך, ובמקרה של ביטול, אי־זמינות הלקוח או חוסר אפשרות לקבל גישה למקום, עשויים לחול דמי הביקור בסך {{5}}, בכפוף להוראות חוק הגנת הצרכן ולכל זכות ביטול שאינה ניתנת להתניה.
```

**Button** — כפתור אחד מסוג **Visit website**, דינמי:

- טקסט הכפתור: `אישור ההזמנה`
- כתובת: `https://<הכתובת-שלכם>/c/{{1}}`

המערכת שמה בסוף הכתובת את הטוקן של אותה עבודה, כך שהכפתור מוביל לדף האישור
האישי של אותו לקוח.

האישור אורך בדרך כלל דקות ספורות.

## מה מזינים ב-Vercel

Project → Settings → Environment Variables. **לא** ב-`NEXT_PUBLIC_` — הערכים
האלה נשארים בשרת ולא מגיעים לדפדפן.

| שם | ערך |
|---|---|
| `WHATSAPP_PHONE_NUMBER_ID` | ה-Phone number ID מ-Meta |
| `WHATSAPP_ACCESS_TOKEN` | הטוקן הקבוע של ה-System User |
| `WHATSAPP_TEMPLATE_NAME` | `order_confirmation` |
| `WHATSAPP_TEMPLATE_LANG` | `he` |

אחרי השמירה צריך **Redeploy** כדי שהערכים ייכנסו לתוקף.

## איך יודעים שזה עבד

הגדרות כלליות → הכרטיס ״שליחה אוטומטית ב-WhatsApp״ יציג **״מחובר״**.

בזמן הבדיקה כדאי להוסיף את המספר הפרטי שלכם ב-Meta תחת Recipients — לפני
שהחשבון יוצא ממצב בדיקה, הודעות נשלחות רק למספרים שברשימה.

## אם משהו לא עובד

השגיאה של WhatsApp מוצגת כמו שהיא בתוך העבודה, כי היא אומרת מה בדיוק חסר:

- *Template name does not exist* — התבנית עוד לא אושרה, או שהשם/השפה שונים.
- *Recipient phone number not in allowed list* — החשבון במצב בדיקה.
- *Invalid OAuth access token* — הטוקן פג. מפיקים טוקן קבוע של System User.

בכל מקרה כזה הכפתור הידני ממשיך לעבוד, ואפשר לשלוח כרגיל.

# שליחת הדוח החודשי לרואה החשבון מה-Gmail שלכם

בלי החיבור הזה הכפתור פותח חלון כתיבה ב-Gmail והדוח כתוב בגוף ההודעה, אבל את
קבצי ה-CSV צריך לצרף ביד. עם החיבור — המערכת שולחת את ההודעה עם שני הקבצים
מצורפים, בלי לפתוח כלום.

## למה צריך סיסמת אפליקציה

Google לא מרשה לאף תוכנה להתחבר עם הסיסמה הרגילה שלכם. **סיסמת אפליקציה** היא
סיסמה נפרדת בת 16 תווים, שמשמשת רק לשליחת מיילים, ואפשר לבטל אותה בכל רגע בלי
לגעת בסיסמה האמיתית.

## איך מפיקים אותה

1. חייבים **אימות דו-שלבי** מופעל בחשבון Google.
   myaccount.google.com ← Security ← 2-Step Verification.
2. myaccount.google.com/apppasswords
3. בשדה השם כותבים למשל `JobCRM` ולוחצים **Create**.
4. Google מציג 16 אותיות בארבע קבוצות. **מעתיקים אותן** — הן לא יוצגו שוב.

## מה מזינים ב-Vercel

Project → Settings → Environment Variables. **לא** ב-`NEXT_PUBLIC_`.

| שם | ערך |
|---|---|
| `GMAIL_USER` | כתובת ה-Gmail שממנה נשלח |
| `GMAIL_APP_PASSWORD` | 16 התווים (רווחים לא מפריעים) |

אחרי השמירה — **Redeploy**.

## איך יודעים שזה עבד

במסך **דוח לרואה חשבון** הכפתור ישתנה ל**״שליחה לרואה החשבון עם הקבצים״**, ומתחתיו
יופיע קישור קטן לשליחה ידנית. אחרי לחיצה מופיעה שורה ירוקה עם הכתובת שאליה נשלח.

## אם משהו לא עובד

- *Gmail דחה את פרטי ההתחברות* — הוזנה הסיסמה הרגילה ולא סיסמת אפליקציה, או
  שהיא בוטלה. מפיקים חדשה.
- *אין נתונים בחודש הזה לשליחה* — החודש שנבחר ריק.
- *לא הוגדר מייל של רואה החשבון* — הגדרות כלליות ← פרטי העסק לקבלות.

בכל מקרה כזה חלון הכתיבה ב-Gmail ממשיך לעבוד כרגיל.
