# מדריך התקנה והעלאה לאוויר — צעד אחר צעד

מדריך זה מיועד למי שאין לו שום ניסיון בתכנות. עקבו אחרי השלבים בדיוק לפי הסדר.
בסוף התהליך יהיה לכם אתר אמיתי בכתובת כמו `my-business.vercel.app` שאפשר להיכנס
אליו מהמחשב ומהטלפון.

התהליך מורכב מ-3 שלבים:

1. **Supabase** — יצירת מסד הנתונים וההתחברות (בחינם)
2. **GitHub** — המקום שבו שמור הקוד (כבר בוצע עבורכם בפרויקט הזה)
3. **Vercel** — פרסום האתר לאינטרנט (בחינם)

---

## שלב 1: יצירת פרויקט ב-Supabase

Supabase הוא השירות שמחזיק את מסד הנתונים (כל העבודות, הקבלנים וכו') ואת מערכת
ההתחברות (Login) של המערכת. יש לו Free Tier נדיב שמספיק בהחלט לעסק בגודל בינוני.

1. גשו לכתובת **https://supabase.com** ולחצו על **Start your project**.
2. הירשמו עם חשבון Google או Email (חינמי, לא דורש כרטיס אשראי).
3. לחצו על **New Project**.
   - **Name**: כל שם שתרצו, למשל `job-crm`.
   - **Database Password**: בחרו סיסמה חזקה ו**שמרו אותה במקום בטוח** (תצטרכו אותה
     רק אם תרצו להתחבר ישירות למסד הנתונים בעתיד).
   - **Region**: בחרו אזור קרוב אליכם (למשל Frankfurt/eu-central).
   - לחצו **Create new project** והמתינו כ-1-2 דקות עד שהפרויקט מוכן.

### 1.1 יצירת מבנה מסד הנתונים

1. בתפריט הצד השמאלי, לחצו על **SQL Editor**.
2. לחצו על **New query**.
3. פתחו במחשב שלכם את הקובץ `webapp/supabase/schema.sql` מתוך הפרויקט, העתיקו
   את **כל** התוכן, והדביקו אותו בעורך ה-SQL בסופרבייס.
4. לחצו על **Run** (או Ctrl+Enter). אמורות להופיע הודעות ירוקות של `CREATE TABLE`
   וכו'. אם הכל ירוק — מסד הנתונים מוכן.
5. פתחו שאילתה חדשה (New query) נוספת, העתיקו את כל התוכן של הקובץ
   `webapp/supabase/seed.sql`, הדביקו ולחצו **Run**. זה ייצור נתוני דוגמה (תחומים,
   ערים, קבלנים ועבודות לדוגמה) כדי שתוכלו לראות מיד שהמערכת עובדת.
   > אפשר לדלג על שלב זה אם אתם רוצים להתחיל ממסד נתונים ריק לגמרי — אבל מומלץ
   > להריץ אותו פעם ראשונה כדי לוודא שהכל עובד, ואז למחוק את הדוגמאות ממסך
   > "הגדרות" באפליקציה עצמה (יש כפתור מיוחד למחיקת נתוני הדוגמה).

### 1.2 יצירת משתמש מנהל (Login)

המערכת היא מערכת עסקית פרטית — רק מי שיש לו שם משתמש וסיסמה יכול להיכנס.

1. בתפריט הצד, לחצו על **Authentication** ← **Users**.
2. לחצו על **Add user** ← **Create new user**.
3. מלאו אימייל וסיסמה שתרצו להתחבר איתם למערכת (זה **לא** קשור לחשבון ה-Google
   שלכם ב-Supabase — זה המשתמש של האפליקציה עצמה).
4. חשוב: סמנו את **Auto Confirm User** (כדי שלא תצטרכו לאשר במייל).
5. לחצו **Create user**.

זהו — זה יהיה שם המשתמש והסיסמה שלכם בכניסה למערכת.

### 1.3 איתור מפתחות ה-API

1. בתפריט הצד, לחצו על **Project Settings** (סמל גלגל שיניים) ← **API**.
2. יופיעו שני ערכים שתצטרכו בהמשך:
   - **Project URL** — כתובת שנראית כמו `https://xxxxxxxxxxxx.supabase.co`
   - **anon public** key — מחרוזת ארוכה שמתחילה ב-`eyJ...`
3. השאירו את הטאב הזה פתוח, נצטרך את הערכים בשלב 3.

## שלב 2: הקוד ב-GitHub

הקוד של המערכת כבר נמצא ב-repository שלכם ב-GitHub (זה בוצע עבורכם בסשן הזה).
אין צורך לעשות כלום בשלב הזה — רק לוודא שאתם יודעים איפה ה-repository נמצא,
כי בשלב הבא תצטרכו לחבר אותו ל-Vercel.

אם בעתיד תרצו להעלות שינויים בעצמכם, תוכלו לעשות זאת דרך GitHub Desktop או
`git push` רגיל — Vercel יזהה אוטומטית כל שינוי ויעדכן את האתר החי.

---

## שלב 3: פרסום ב-Vercel

Vercel הוא שירות אירוח חינמי שמתמחה באתרי Next.js — הכי פשוט לחיבור.

1. גשו לכתובת **https://vercel.com** ולחצו **Sign Up**.
2. הירשמו **עם חשבון ה-GitHub שלכם** (חשוב לבחור "Continue with GitHub") — כך
   Vercel יוכל לגשת ל-repository שלכם.
3. לאחר ההרשמה, לחצו על **Add New...** ← **Project**.
4. אתרו ברשימה את ה-repository של הפרויקט הזה ולחצו **Import**.
5. במסך ההגדרות שנפתח (**Configure Project**):
   - **Root Directory**: לחצו **Edit** ובחרו את התיקייה **`webapp`** (חשוב מאוד —
     קוד ה-CRM נמצא בתת-תיקייה כדי לא להתנגש עם דף הנחיתה הקיים בשורש הפרויקט).
   - **Framework Preset**: אמור לזהות אוטומטית **Next.js**.
6. לפני שלוחצים על Deploy — פתחו את **Environment Variables** והוסיפו שני משתנים
   (את הערכים לקחתם משלב 1.3):

   | Name | Value |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | ה-Project URL מסופאבייס |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ה-anon public key מסופאבייס |

7. לחצו על **Deploy** והמתינו כ-1-2 דקות.
8. בסיום תקבלו כתובת קבועה כמו **`your-project-name.vercel.app`** — זו הכתובת
   הקבועה של המערכת שלכם! אפשר (ורצוי) לשנות אותה בהמשך מתוך Project Settings ←
   Domains, גם לדומיין פרטי אם יש לכם אחד.

### עדכון עתידי

בכל פעם שהקוד ב-GitHub יתעדכן (למשל דרך סשן נוסף כאן), Vercel יבנה ויפרסם
גרסה חדשה **אוטומטית** תוך דקה-שתיים, בלי שום פעולה נוספת מצדכם.

## שלב 4: כניסה למערכת

1. פתחו את הכתובת `your-project-name.vercel.app` בדפדפן (מחשב או טלפון).
2. הזינו את האימייל והסיסמה שיצרתם בשלב 1.2.
3. זהו — אתם בתוך המערכת.

---

## שלב 5: התקנה כאפליקציה בטלפון (PWA)

### אנדרואיד (Chrome)
1. פתחו את כתובת האתר בכרום.
2. לחצו על שלוש הנקודות בפינה ← **התקן אפליקציה** (Add to Home screen).
3. אשרו — יופיע אייקון בדיוק כמו אפליקציה רגילה במסך הבית.

### אייפון (Safari)
1. פתחו את כתובת האתר ב-Safari (**חובה** Safari, לא כרום, בגלל מגבלת אפל).
2. לחצו על כפתור השיתוף (הריבוע עם החץ למעלה).
3. גללו ובחרו **הוסף למסך הבית** (Add to Home Screen).
4. אשרו — יופיע אייקון במסך הבית שנפתח במסך מלא בלי סרגלי דפדפן.

### הפעלת התראות בדפדפן
בתוך המערכת, לכו למסך **הגדרות** ולחצו על **הפעלת התראות** כדי לקבל התראה
כשעבודה לא נסגרת יותר משעתיים, גם אם האתר פתוח רק ברקע.

## מחיקת נתוני הדוגמה לפני עבודה אמיתית

בתוך המערכת: **הגדרות** ← גללו לתחתית ← **מחיקת כל נתוני הדוגמה** (כפתור אדום).
פעולה זו מוחקת את כל העבודות והקבלנים לדוגמה, אך משאירה את התחומים, סוגי
העבודה, הערים והסטטוסים שהגדרתם (אפשר לערוך אותם בנפרד במסכי ההגדרות).

אפשר גם לבצע זאת ידנית ב-SQL Editor של Supabase:

```sql
delete from jobs;
delete from settlements;
delete from contractors;
```

## בעיות נפוצות

**"Invalid API key" בכניסה למערכת** — בדקו שהעתקתם נכון את ה-`anon public key`
(לא את ה-`service_role` key, שאסור לחשוף בצד לקוח) ושהוספתם אותו כ-Environment
Variable ב-Vercel, ואז ביצעתם **Redeploy** (Vercel לא מיישם משתנים חדשים על
build ישן).

**מסך לבן / שגיאה אחרי כניסה** — ודאו שהרצתם גם את `schema.sql` וגם את `seed.sql`
(או לפחות את `schema.sql`) ב-SQL Editor של Supabase לפני הכניסה הראשונה.

**כתובות לא מוצעות בשדה הכתובת** — חיפוש הכתובות תלוי בזמינות שירות Nominatim
החיצוני (חינמי, לפעמים איטי במיוחד). אפשר תמיד להקליד כתובת ידנית — היא עדיין
תישמר בעבודה, רק בלי קואורדינטות מדויקות למפה.
